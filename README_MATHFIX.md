# ZeroAI v1.8 MathFix — 計算修正版

ZeroAI v1.8を土台に、**計算が必要な質問をGPTの推測で答えさせない**ようにしたパッチです。
学習済みの `v15_best.pt` は変更せず、再学習や外部AI・RAG・外部APIを使用しません。

## 原因
公開GitHub Pagesの `gh-pages/index.html` は、確認時点でv1.7でした。
v1.7にはv1.8の計算エンジン (`math_v18.js`) が存在しないので、
`125 * 24` に `121です。` と返るのは、モデルが誤った数字を生成した可能性があります。

## Windows
- 起動: `run_v18.bat` （モデル入りZIPで実行）
- [1] 日本語会話・ローカル計算
- [8] MathFixの検算だけを試す（モデル読み込み・ネット不要）
- CLI単体: `python math_v18.py "125 * 24" "125 × 24 は？"`
- 数学が検出された場合の処理: Python標準の `ast` で式を安全に解析し、`Decimal` で計算します。
  `eval`・`exec`・生成コードの任意実行はしません。
- 解ける文章問題: 分配、個数の加減算、個数×人数など限定パターン。
- 未対応の文章問題は「検証済み」と表示せず、学習済みGPTへ送られます。
- 数式の結果は `[SOURCE] Python AST + Decimal / VERIFIED LOCAL MATH (not GPT)` と表示。

## Web（GitHub Pages / Windows PC・iPhone）
- GitHub Pagesには **Web_Source内のソースだけ**を公開してください。
- `math_v18_fix.js` が安全な数式パーサー（BigIntベース）です。
- 明確な数式は「Pythonコード検証ON」でも「文章問題検算OFF」でもローカル計算します。
- WebではPython自体は動かしていません。数式の検算のみPythonと同様の結果になるように実装。
- 「125×24 の計算テスト」ボタンでは、モデルの有無にかかわらず3000と表示します。
- WebでAIの回答を作るには従来どおり、**自分の非公開のモデル**
  `manifest.json / tokenizer.json / weights.bin` をブラウザ内に取り込みます。
- GitHub Pagesには絶対に `weights.bin` や学習済みチェックポイントを公開しないでください。
- キャッシュ更新: HTMLはMathFixと表示、`sw.js` はv1.8 MathFix用に変更。更新後は
  `https://chika1147.github.io/sora1147/?mathfix=20261119`
  を使うと旧キャッシュを避けやすくなります。

## 大事な制限
* 数学の検算が強化されたのであって、ニューラルモデル自身が数学を理解できるように追加学習したわけではありません。
* 文章問題の言葉を誤解すると誤った式になることがあります。対応パターンを限定しています。
* WebのPythonコード生成結果そのものは実行していません。
* 実際のWindows 11実機とiPhone Safariでの操作テストは今回の環境では未実施です。
